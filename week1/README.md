# Трекер расходов

Консольная утилита на Python. Читает CSV-файл с расходами (`дата,категория,сумма`) и печатает суммы по категориям, по месяцам и по годам. Можно отфильтровать результат по границам суммы и по году.

## Требования

Python 3.12 или новее. Сторонние библиотеки не нужны.

## Запуск

Команды выполняются из корня репозитория:

```bash
python homework.py expenses.csv
```

Фильтры (необязательные):

```bash
python homework.py expenses.csv --min 50000
python homework.py expenses.csv --max 100000
python homework.py expenses.csv --min 20000 --max 100000
python homework.py expenses.csv --year 2026
```

| Флаг | Что делает |
|---|---|
| `--min N` | показать только суммы не меньше N |
| `--max N` | показать только суммы не больше N |
| `--year Y` | учитывать только расходы за год Y |

`--min` и `--max` применяются ко всем трём блокам (категории, месяцы, годы). `--year` отсекает расходы до подсчёта. Справка: `python homework.py -h`.

## Формат CSV

Файл в кодировке UTF-8 с заголовком:

```text
date,category,amount
2026-01-05,Еда,2500.00
2026-01-09,Транспорт,1000.00
```

- `date` — дата в формате `YYYY-MM-DD`;
- `category` — название категории;
- `amount` — положительное число, десятичный разделитель — точка.

## Обработка ошибок

Программа не показывает traceback, а печатает одну строку в `stderr` и завершается с кодом 1:

| Ситуация | Сообщение |
|---|---|
| файла нет или это папка | `Ошибка: не удалось прочитать файл (...)` |
| расширение не `.csv` | `Ошибка: ...` |
| файл пустой или только заголовок | `Ошибка: Файл пустой` |
| неверная дата или сумма, нет колонки | `Ошибка: строка N: неверные данные` (N — номер строки в файле) |
| сумма `0`, отрицательная, `nan` или `inf` | `Ошибка: строка N: ...` |
| файл не в UTF-8 | `Ошибка: файл не в кодировке UTF-8` |

## Как устроен код

- `list` — список расходов и список строк файла;
- `tuple` — один расход `(date, категория, сумма)`;
- `dict` — строка CSV и итоговые суммы;
- comprehension — в `load_expenses`, `format_totals`, `apply_filter`;
- функция высшего порядка — `group_sum(expenses, key)` принимает функцию-ключ (`category_of`, `month_of`, `year_of`);
- замыкание — `make_range_filter(low, high)` возвращает функцию `check`, которая помнит границы;
- у всех функций есть аннотации типов;
- ошибки ввода: собственное исключение `InputError`, которое ловится в `main`.
